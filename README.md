# QSE Robotics

An early web design project celebrating QSE Robotics, a VEX team at Pinnacle View Middle School in Little Rock, Arkansas.

Created by **Anay Pandit** as a code-camp project, this website connects an interest in robotics with the beginnings of learning to build for the web.

**[View the website](https://anaypandit.github.io/code-camp/)**

## Inside the project

- A team introduction and robotics background.
- Competition stories and a photo gallery.
- Team branding, contact information, and community links.

Built with **HTML, CSS, and JavaScript**, using jQuery and Slick for the gallery.

This repository captures an early stage of the project. For the broader robotics story and later milestones, [visit Anay's portfolio](https://anaypandit.github.io/projects/vex-robotics/).
